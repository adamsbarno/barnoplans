# Image Naming Standard

Use this naming pattern for every new house-plan upload:

- Main view: images/4-bedroom-maisonette-main.jpg
- Exterior view: images/4-bedroom-maisonette-exterior.jpg
- Floor plan: images/4-bedroom-maisonette-floor-plan.jpg
- PDF: pdfs/4-bedroom-maisonette.pdf

General pattern:
- bedroom count first
- type or view second
- lowercase, hyphen-separated names only

Examples:
- 3-bedroom-house-main.jpg
- 3-bedroom-house-exterior.jpg
- 3-bedroom-house-floor-plan.jpg
- 2-bedroom-family-home.pdf

Keep the file names consistent with the plan catalog in [data/plans.js](../data/plans.js).
